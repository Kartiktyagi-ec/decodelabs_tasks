## Project Description

This project is a Smart Environmental Monitor developed using an ESP32, DHT22 sensor, and a 16x2 I2C LCD. The system measures real-time temperature and humidity and displays the values on the LCD as well as the Serial Monitor.

***

### Components Used

* ESP32 Development Board
* DHT22 Temperature & Humidity Sensor
* 16x2 I2C LCD Display
* Breadboard
* Jumper Wires
* USB Cable

***

## Software Used

* Arduino IDE
* ESP32 Board Package
* DHT Sensor Library
* LiquidCrystal-I2C Library

***

## Features

* Real-time Temperature Monitoring
* Real-time Humidity Monitoring
* LCD Display Output

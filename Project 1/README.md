# Smart Environmental Monitor

A Smart Environmental Monitor developed as part of the DecodeLabs IoT Internship.

##  Developed By

**Kartik Tyagi**

**Branch:** Electronics and Communication Engineering (ECE)

##  Project Description

This project is a Smart Environmental Monitor developed using an ESP32,
DHT22 temperature and humidity sensor, and a 16x2 I2C LCD.

The system measures temperature and humidity and displays the readings on
the LCD as well as on the Serial Monitor.

##  Components Used

- ESP32 Development Board
- DHT22 Temperature & Humidity Sensor
- 16x2 I2C LCD Display
- Jumper Wires
- Breadboard
- USB Cable

## Features

- Real-time temperature monitoring
- Real-time humidity monitoring
- LCD display output
- Serial Monitor output
- ESP32-based IoT project

## Software Used

- Arduino IDE
- ESP32 Board Package
- DHT Sensor Library
- Liquid Crystal I2C Library

The system displays the measured temperature and humidity values on the
16x2 I2C LCD and Serial Monitor.
